# VISEMFOOD Website & Admin Platform Quotation

**Date:** August 16, 2026  
**Prepared For:** VISEMFOOD  
**Prepared By:** Digital Project Proposal Draft  

## 1. Project Title
**Development of the VISEMFOOD Premium Culinary, Catering, and Dynamic Admin Platform**

## 2. Project Summary
This quotation covers the design refinement and development of a premium digital platform for VISEMFOOD. The proposed solution includes a fully dynamic customer-facing website with an e-commerce-style `Order Now` page, guided WhatsApp ordering, catering and bulk order inquiries, brand storytelling, and an internal admin dashboard for operational management and live content updates.

The goal is to deliver a platform that reflects the VISEMFOOD brand standard while improving customer experience, order visibility, and internal workflow efficiency.

## 3. Scope of Work

### A. Customer-Facing Website
- Homepage
- Dynamic `Order Now` product catalog page
- Dynamic product detail pages
- Pre-filled WhatsApp launch on every order action with the selected product
- Trays, coolers, and bulk ordering page
- Catering services page
- Catering inquiry form
- Contact page
- Our Story / brand heritage page

### B. Dynamic Admin Platform
- Admin dashboard overview
- Bulk orders management
- Catering inquiries management
- Dynamic website content management
- Dynamic product and service management

### C. General Delivery Items
- Responsive desktop and mobile design implementation
- UI refinement from existing mockups
- Basic form handling workflows
- WhatsApp order message flow setup
- Database-backed dynamic content structure
- Search and filter capability on the `Order Now` page
- Content structure implementation
- Launch readiness review

## 4. Deliverables
- Fully responsive VISEMFOOD website
- Branded interface aligned with the approved visual direction
- Customer inquiry and catering request workflows
- WhatsApp-based order confirmation flow
- Dynamic `Order Now` catalog page
- Dynamic product and content management system
- Bulk ordering information architecture
- Contact and support information pages
- Internal admin dashboard modules
- Inquiry and order management interfaces

## 5. Project Duration
Estimated project duration: **7 to 10 weeks**

### Proposed Breakdown
- Discovery and planning: 1 week
- UI refinement: 1 to 2 weeks
- Development: 4 to 6 weeks
- Testing and launch preparation: 1 week

Timeline is subject to timely feedback, content availability, and final scope confirmation.

## 6. Pricing Options

### Option A: Brand Website + Inquiry Platform
Includes homepage, story, contact, catering pages, inquiry forms, trays and coolers information, guided WhatsApp ordering, and lightweight internal handling workflow.

**Fee:** `NGN 3,500,000 - NGN 5,500,000`

### Option B: Full Dynamic Platform + Admin Operations
Includes the complete public-facing website plus admin dashboard, catering inquiry management, bulk order management, dynamic content tools, dynamic product management, and WhatsApp order flow implementation.

**Fee:** `NGN 8,000,000 - NGN 12,000,000`

### Option C: Full Premium Dynamic Build + Expansion Readiness
Includes the full platform, scalable architecture planning, advanced operational structure, and readiness for future integrations such as payments, CRM, analytics, and loyalty features.

**Fee:** `NGN 12,500,000 - NGN 18,000,000`

## 7. Recommended Commercial Option
Based on the reviewed materials, the most suitable starting point for VISEMFOOD is:

**Recommended Option: Option B - Full Dynamic Platform + Admin Operations**

### Recommended Price Band
**NGN 9,500,000**

This level provides enough depth to launch a polished customer experience while also giving the VISEMFOOD team the internal tools needed to manage inquiries, bulk requests, product content, live website updates, and the `Order Now` product catalog.

## 8. Payment Terms
A recommended milestone structure is as follows:

- **40% upfront deposit** to commence project
- **35% upon design and development midpoint**
- **25% upon final delivery before launch**

For a recommended project value of `NGN 9,500,000`, this would be:

- Upfront deposit: `NGN 3,800,000`
- Midpoint payment: `NGN 3,325,000`
- Final payment: `NGN 2,375,000`

## 9. What Is Included
- Planning and scope alignment
- UI implementation based on provided concept direction
- Frontend and admin interface development
- Dynamic backend and content management structure
- Standard responsiveness across desktop and mobile
- Basic QA and launch preparation

## 10. What Is Not Included Unless Separately Approved
- Custom mobile app development
- Third-party paid software subscriptions
- Advanced delivery fleet integration
- Full e-commerce payment processing setup
- Ongoing monthly maintenance retainer
- Large-scale copywriting or food photography production

## 11. Assumptions
- VISEMFOOD will provide or approve content, pricing, menu information, admin WhatsApp details, and operational rules.
- The first release will prioritize a responsive website rather than native mobile apps.
- The `Order Now` page will serve as the main product listing and ordering catalog.
- Customer orders in phase one will be handled through a pre-filled WhatsApp confirmation flow instead of built-in checkout.
- The backend will support live editing of products, page content, and service information.
- Features such as payment gateways, customer accounts, and loyalty tools may be handled as phase-two enhancements unless included in the final approved scope.
