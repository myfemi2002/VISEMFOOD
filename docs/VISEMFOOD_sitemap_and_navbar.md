# VISEMFOOD Final Sitemap and Navbar Structure

## Purpose
This document defines the final website structure and navigation flow for the VISEMFOOD platform based on the current agreed direction:

- fully dynamic website
- `Order Now` as the main e-commerce-style catalog page
- WhatsApp used as the final order confirmation and arrangement channel
- no standalone `Delivery` page

## Final Navbar
The website navbar should remain clean, premium, and easy to understand.

### Recommended Navbar Items
- `Home`
- `Order Now`
- `Trays & Coolers`
- `Catering`
- `Contact`
- `Our Story`

### Navbar CTA Behavior
- The main ordering action should be tied to `Order Now`
- `Order Now` should open the product catalog page, not WhatsApp directly
- Individual product buttons inside the catalog should open WhatsApp with product-specific details

## Navbar Layout Recommendation

### Desktop Navbar
- Left: `VISEMFOOD` logo
- Center or right: navigation links
- Highlight `Order Now` as the main emphasis item

### Mobile Navbar
- Logo at top or left
- Hamburger menu for navigation links
- `Order Now` should remain visually prominent inside the menu or as a visible button

## Final Sitemap

### 1. Home
The homepage introduces the VISEMFOOD brand and directs users to key journeys.

#### Suggested Sections
- Hero section
- Signature meals preview
- Trays & Coolers highlight
- Catering highlight
- Brand story preview
- Contact or inquiry prompt

### 2. Order Now
This is the main product catalog page and should behave like an e-commerce listing page.

#### Key Purpose
- display all available food products
- allow users to browse, filter, and search
- redirect users to WhatsApp after selecting a product

#### Suggested Sections
- Page hero or intro
- Search bar
- Category filters
- Product grid
- Product cards
- Order note explaining WhatsApp confirmation

### 3. Product Detail
This is an optional but recommended dynamic page for individual items.

#### Key Purpose
- show full product information
- give the user more confidence before ordering
- provide another `Order Now` action

#### Suggested Sections
- Product image gallery
- Product title
- Description
- Price
- Serving or portion info
- Related products
- `Order Now` button

### 4. Trays & Coolers
This page is for bulk and event-based food requests.

#### Key Purpose
- present tray and cooler package options
- explain bulk ordering expectations
- redirect users to WhatsApp for package confirmation

#### Suggested Sections
- Intro banner
- Package listings
- Serving details
- Bulk order notes
- CTA to WhatsApp

### 5. Catering
This page positions VISEMFOOD as a premium event and hospitality service provider.

#### Key Purpose
- present catering offer
- explain event support
- lead users to the catering inquiry form

#### Suggested Sections
- Catering hero section
- Service overview
- Event types served
- Catering value points
- CTA to inquiry form

### 6. Catering Inquiry Form
This page captures formal event-related requests.

#### Key Purpose
- collect structured information for catering leads

#### Suggested Fields
- Full name
- Phone number
- Email address
- Event type
- Event date
- Guest count
- Preferred menu
- Additional notes

### 7. Contact
This page gives users direct access to support and inquiry channels.

#### Key Purpose
- provide general communication options
- support non-order questions
- support bulk and catering follow-up

#### Suggested Sections
- Contact form
- Phone number
- WhatsApp number
- Email address
- Address if needed
- Business hours

### 8. Our Story
This page builds trust and emotional connection with the brand.

#### Key Purpose
- communicate the VISEMFOOD identity
- present brand heritage and hospitality values

#### Suggested Sections
- Brand story hero
- Mission or philosophy
- Hospitality values
- Cultural authenticity narrative

## Recommended User Flow

### Standard Food Order Flow
1. User visits `Order Now`
2. User browses product catalog
3. User clicks `Order Now` on a product
4. WhatsApp opens with a pre-filled message
5. Admin handles confirmation, payment, and arrangement

### Bulk Order Flow
1. User visits `Trays & Coolers`
2. User selects a package
3. User clicks order or inquiry CTA
4. WhatsApp opens with package details
5. Admin handles arrangement and follow-up

### Catering Flow
1. User visits `Catering`
2. User reads service information
3. User clicks through to `Catering Inquiry Form`
4. Inquiry is submitted
5. Admin reviews and responds

## Dynamic Structure Requirement
The following pages should be dynamic:

- `Home`
- `Order Now`
- `Product Detail`
- `Trays & Coolers`
- `Catering`
- `Catering Inquiry Form`
- `Contact`
- `Our Story`

## Conclusion
The final website structure keeps VISEMFOOD focused, premium, and conversion-oriented. The navigation is simple, the ordering flow is clear, and the WhatsApp confirmation model is supported without making the website feel limited. This structure is well suited for a dynamic hospitality platform with room to grow over time.
